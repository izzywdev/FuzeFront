Rules the implementation must keep

  • The picker takes the width of the host field and never imposes a minimum width that would scroll the host page at 375 px.
  • Below 40em the menu opens inline, in the flow under the control (data-menu-placement="inline") instead of as an absolutely-positioned popover, so a host container with overflow: hidden cannot clip it and the on-screen keyboard cannot cover it. The filter input keeps focus while the keyboard is open.
  • Options, the control and the filter are ≥ 44 px (--touch-target). Chip remove targets are padded to at least --space-6 and spaced apart; Clear all becomes its own full-width button under the chips.
  • RTL (ar, he): the host's dir drives the picker — label, value and options align to the start, the caret sits at the inline end; ids in the inspector stay LTR.
  • Archived and purged stored values render exactly as in frame 4c; every state renders inside the field, never by throwing into the host.
