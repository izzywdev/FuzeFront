Rules the implementation must keep

  • At ≤ 40em the locale grid is one column and the bilingual editor stacks source above translation in each row — the source is never hidden behind a tap, because a translator can't translate what they can't see.
  • “Save all” and “Autofill missing” sit in a sticky bar at the bottom of the screen, above the home-indicator inset (--safe-area-bottom). Per-row actions (Mark reviewed, Keep as-is, Save row) are full-width and ≥ 44 px tall.
  • RTL is per cell, not per page. In a Hebrew UI editing Arabic, the chrome is RTL, the source stays dir="ltr" (it is English), and the target input is dir="rtl". Never a per-locale stylesheet.
  • The autofill confirmation is a BottomSheet with the same count, source locale and human-preservation guarantee as frame 2c; overwrite_machine defaults off; progress is determinate; a partial failure keeps what was written.
  • Machine output stays badged M and the Source changed warning is inline on its row at every width.
