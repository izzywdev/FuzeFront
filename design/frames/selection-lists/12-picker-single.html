States

The picker is embedded in someone else's form. It must never blow up that form, and must never silently render an empty control.

▾

Skeleton inside the control at its final height — the surrounding form never reflows when values arrive.

No options available ▾

ℹ The list exists but has no active values — every value is archived, or none was ever added. The control is disabled and says so, rather than opening an empty menu.

Couldn't load options

⚠ The picker fails visibly and locally: it shows a retry in place and keeps any already-selected value. It never throws into the host form's render tree, and never submits a silently-empty field.

List unavailable

⚠ No list with key sales-regions in this organization, or the viewer can't read it — the service answers 404 either way, so the picker cannot be used to probe another org's lists.
