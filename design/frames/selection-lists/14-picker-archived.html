{ "label": "EMEA South", "locale": "en", "is_machine": false, "status": "archived" }

Archived items resolve normally. The caller styles them as retired using status — the service does not hide them, because a consumer's stored reference must stay readable forever.

ℹ

Readable, but not re-selectable

An archived value renders when it is already stored, and is absent from the menu — so nobody can newly pick a retired option, while every existing record keeps its meaning. If the user changes the region, the archived option is gone for good.
