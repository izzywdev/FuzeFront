(c5) Loading — first GET /build-sessions/{id}

Updates. The contract has no push channel for sessions, so the flow polls GET /build-sessions/{id} while the status is in-flight (requested, launching, building, deploying): every 5 s for the first minute, then backing off to 30 s, paused while the tab is hidden, stopped on a terminal status. The status pill and stepper announce changes through aria-live="polite".
Agent deep link. Rendered only when agentSessionUrl is non-null and resolves to the shell's own origin (/app/fuzeagent/…); it navigates in-shell. A cross-origin or malformed URL is not rendered as a link — fail-closed against an open redirect.
Cancel. Shown to the requester and org managers while in-flight. A 409 on cancel means the session reached a terminal state first: refetch and render that state (frame d), no error toast.
