Behaviour. The card is a role="button" with tabIndex=0, activated by click, Enter or Space — identical to the Add card. It routes to /applications/build (frame b). In (a4) the latest non-terminal session from GET /build-sessions?limit=1 turns the card into a resume link to /applications/build/:sessionId; that read only happens when the flag is ON.
Flag. fuzefront.apps.build-with-agent, release, default OFF, builders audience. OFF ⇒ the component returns null. The page change is a single mount of <BuildAppCard /> from @fuzefront/app-builder-ui after the Add card — the card's own markup and logic live in the package.
