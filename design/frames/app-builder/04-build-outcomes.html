Deployed. The tile comes from the normal GET /apps list — no special-casing; the flow invalidates that query when the session turns deployed and links appSlug. Open app uses the app's normal route. Failed vs refused: failed is a session that exists (from the agent callback, or 502 launch_failed); a 503/403/409/429 at submit created nothing. Copy never blames the user for a platform fault.
Authz. 403 is shown in place; only 401 re-authenticates. A session the caller can't see is 404 by contract — the UI never distinguishes "forbidden" from "missing".
