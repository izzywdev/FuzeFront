Catalog — browse product → service → spec

The aggregated index over every harvested openapi.yaml in the family. Left rail is a collapsible TreeNav (product → service → spec); the main column is a filterable result list. Each result states its sandbox mode up front — mock (spec-generated, the default) or sandbox (the repo opted a real sandbox URL in) — because that determines whether "Try it" will do anything useful.
