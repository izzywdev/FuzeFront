Overview

Registers and resolves the applications mounted into the FuzeFront shell — federated remotes and standalone apps alike. Every entity id is a wire-typed TypeID minted by this service; slug is immutable after registration.

tag: apps tag: health tag: manifests auth: bearer (Authentik)
POST /api/v1/apps Try it →

Register an application

Creates an app registration. The id is minted by this service — a client-supplied id is rejected (additionalProperties: false).

Request body · AppRegistration

FieldTypeDescription
slug requiredstring Immutable. Free-form at creation; never renamed by a later PUT.
name requiredstring Display name. Drops the Fuze prefix except for FuzeBI / FuzeX.
integrationobject remoteEntry resolved against the host origin for federated remotes.
routingobject path is independent of slug.

Responses

201 Created — App application/json
400 Invalid body — ErrorBody application/json
409 Slug already registered — ErrorBody application/json
