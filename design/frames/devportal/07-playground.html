Playground — request builder, response, quota

The "Try it" panel. Three things are always visible and never dismissible: the target this request will actually hit, the statement that it is not production, and the remaining quota. A developer must never have to guess which system they are about to touch.

This never touches production.

Requests are brokered by devportal-service to a mock generated from this spec (Prism), or to a sandbox URL the owning repo explicitly opted in. A production servers: entry is never called. Your Fuze session token is not forwarded — the proxy mints a synthetic sandbox identity scoped to that target only, so a bug in a mock can't be tricked into treating you as a real principal.
