Rules the implementation must keep

  • Direction comes from the locale (he, ar → dir="rtl" on the package root), never from a per-component prop. Layout uses logical properties only (inline-start/end, text-align: start), so nothing is re-specified for RTL.
  • Keys, codes, ids and API paths are LTR islands — dir="ltr" + bidi isolation — so the punctuation and numbers around priority never jump to the wrong side of Hebrew or Arabic text. Item codes are never translated.
  • Labels come from the service in the requested locale (locale=he|ar); the frame's Hebrew/Arabic labels stand in for the list's own translations. UI chrome strings come from the package's i18n catalog.
  • At ≤ 40em (≈ 640 CSS px) the shell's side navigation collapses to the menu button, the item-id column is dropped, the primary action becomes full-width and sits above the notice, and touch targets are at least --space-10 tall.
  • The common-list badge glyph (◎) and the fork glyph (⑂) are not directional and are not mirrored; chevrons and back-arrows are.
