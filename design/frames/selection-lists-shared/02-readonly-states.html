States

Every state below is contract. A consumer that renders only the ready table is incomplete. The detail route is the same for every visibility; only the badge, the notice and the way forward change.

Loading

Badge + notice wait for the list; never guess “editable”

No edit controls and no Fork CTA render until editable and visibility are known — a control that flashes and disappears reads as a bug.

Empty — a readable list with no active values

☰

No values to pick from

This list has no active values yet. Forms that use it show “No options available”. Only someone with a role on the list can add values.

No “+ Add value” in the empty state for a read-only viewer — the 4.0.0 empty state's CTA is gated on editable.

Error — the list loaded, its values didn't

⚠

Couldn't load values

Nothing has been changed. The badge and notice above stay — they came from the list, which did load.

Not found — another organization's list, or no shared read

∅

List not found

No list with that id, or you can't read it. An org list of another organization, or a caller without shared read (the developer role), gets 404 — never 403 — so this URL can't probe whether a list exists.
