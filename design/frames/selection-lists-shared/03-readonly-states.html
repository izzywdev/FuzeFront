Shared with everyone in Acme Logistics

You can view this list and pick its values in forms. Being a member lets you read a list, never change it. To change it, ask the list's owner for an editor role. It was created by a user, not set up automatically.

No Fork here: this list already belongs to your organization, so a fork is refused (409 fork_not_applicable) and the UI never offers one. There is no in-app access request, and the list's roster is not visible to you, so the notice names no person: it says only what created_by proves.

created_by user

created_by system
“It was set up automatically for your organization.”
created_by deleted user
“Its creator's account has been deleted.”

created_by is an AuthorPrincipal — a user id, a system principal or the deleted-user sentinel, decided offline by its prefix — and never a display name. The hint branches on that form only; it never renders the raw identifier, never claims the creator is still a member, and never looks a usr_ value up (no directory read is part of this contract, and a member without a role cannot read the list's roster).

∅

List not found

No list with that id, or you can't read it. Another organization's org list, or a caller without shared read (the developer role), gets 404 — never 403 — so this URL can't probe whether a list exists.
