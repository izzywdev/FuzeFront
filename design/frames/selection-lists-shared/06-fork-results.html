Selection Lists · Priority · Fork — every answer

Every answer to “Fork list”

The UI branches on HTTP status + code + reason only — never on message. Success closes the dialog and navigates; every refusal keeps the dialog open with the answer in place of the options, and never loses where the user came from.

201 Created — a new fork

Lands on the fork's detail, with a toast

⑂ Forked. Globex Freight now uses its own Priority in every form. You're its owner.

Route: /settings/selection-lists/{fork.id} from list.id in the 201 body. The detail shows the editable 4.0.0 value editor plus the provenance card in its “comparison unavailable” state (frame 7): under 4.1.0 the 201 carries only forked_from.revision and the source exposes no current revision, so a new fork is never shown as “up to date”. The list index is refreshed: the common Priority leaves the Common group and the fork appears under Your organization.

Private draft variant

⑂ Draft fork created. Only people with a role see it — everyone else still uses the common list until you set it to Organization.

200 OK — your organization already had a fork

Existing fork, active

⑂

You're on your organization's existing version

Globex Freight already had a fork of Priority (made Sep 2). Nothing new was created and nothing was copied.

Shown on arrival at the existing fork's detail (the dialog closes and navigates, as for 201). Not an error: no red, no retry.

Existing fork, archived (it was the “revert to common”)

⑂

Your organization's fork is archived

Forms use the common list while it's archived. Restore it to use your version again — its values and translations are as you left them.

“Restore” is PATCH {"status":"active"} and renders only when the fork's editable is true; a 403 on it shows the 4.0.0 permission message.

Refusals — shown inside the dialog

409 CONFLICT · reason fork_exists

⑂

Your organization already has a fork you can't see

Someone in Globex Freight forked Priority as a private draft. A second fork isn't possible. Ask whoever is preparing it for a role, or an admin to set it to Organization.

Close

The 409 carries no fork id (you can't read it), so there is nothing to link to and the UI does not invent one. Not retryable.

409 CONFLICT · reason fork_not_applicable

☰

This list already belongs to your organization

There's nothing to fork — ask the list's owner for an editor role instead.

Close

Defensive only: the CTA is never offered on an org/private list (frame 3). Reaching this means stale data; the detail reloads on close.

409 CONFLICT · no reason — the key is taken by another list

⚠

Your organization already has a list with the key priority

It isn't a fork of this common list (for example, an older copy made before common lists existed), so a fork can't take its key. Nothing was created.

Back to lists

The plain 409 proves only the key collision. The colliding list may be archived, private or otherwise unreadable to you, so the copy never says forms use it, never names or links it, and the UI looks nothing up. “Not a fork of this common list” is derivable: a fork of this source would have answered 200 or fork_exists.

403 QUOTA_EXCEEDED · scope org_lists | user_lists | list_items

▣

Globex Freight has reached its list limit

100 of 100 organization lists are in use. A fork is a new list, so it counts. Archive a list you no longer need, or ask an admin about the limit. Nothing was created.

user_lists
“You've reached the number of lists you can own (25 of 25).”
list_items
“This common list has more values (312) than a list in your organization may hold (250).”
Close

Copy is chosen by scope, numbers come from limit/current — the approved 4.0.0 QuotaWarning wording. An unknown scope falls back to “A limit was reached”.

400 VALIDATION_ERROR — source over 5000 values

▣

This list is too large to fork

Lists with more than 5,000 values (archived ones included) can't be forked. You can still pick from it in every form.

Close

The dialog also pre-empts it: when the loaded source has more than 5,000 non-purged values, the confirm button is disabled with this text before any request. The 400 path stays for a source that grew meanwhile.

403 FORBIDDEN — you can't create lists

⚠

You can't fork lists in Globex Freight

Forking creates a list, and your role can't create lists. Ask an admin or editor to fork Priority.

Close

After this the detail page replaces its Fork CTA with this explanation for the rest of the session.

404 NOT_FOUND — the source is gone or unreadable

∅

This list is no longer available

It may have been removed. Nothing was created.

Back to lists

Network failure / 5xx — outcome unknown

⚠

We couldn't confirm the fork

The connection failed before the service answered, so the fork may or may not exist. Trying again is safe — if it was created, you'll be taken to it.

Close

Retry re-sends the same body; the service is idempotent per (organization, source), so a fork created by the lost request comes back as 200 → existing.
