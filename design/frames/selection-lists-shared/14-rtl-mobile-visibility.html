Rules the implementation must keep

  • At ≤ 40em the options are full-width radio cards (DS RadioCardGroup), each ≥ 44 px, at the top of the Access tab; the roster below becomes one card per person. Customer organizations never see the “Every organization” option — not even disabled.
  • Organization → Private opens a BottomSheet with the same four consequence lines as frame 4a (fork lines only when forked_from is set). Cancel holds initial focus. Private → Organization saves directly and toasts.
  • Platform publish is a BottomSheet with the typed key. The key field is dir="ltr", monospaced, with autocapitalize, autocorrect and spellcheck off so a phone keyboard cannot alter what is typed; Publish enables only on an exact match.
  • Read-only is a statement, not a disabled form: non-owners see the current visibility and who can change it.
  • RTL: organization names and keys are bidi-isolated; quotation marks follow the locale („…” in Hebrew); visibility glyphs are not mirrored.
