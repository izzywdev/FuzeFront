The consolidated user menu

Account, organization and language are all answers to “who am I right now”, so they live in one surface: the avatar menu. The organization switcher and the language selector are removed from the top bar — the bar keeps only the hamburger, brand, app launcher, theme toggle, bell and avatar.

Right-to-left languages flip <html dir> through the shared direction manager.

  • Switching organization updates the active org for the active account only — org selection is stored per account, never browser-wide.
  • The account count reads n / 5 so the cap is visible before it is hit, not only when “Add account” refuses.
  • The Admin row is gated on the active account's admin role. Switching to a non-admin account removes it.
  • Sign out at the bottom signs out the active account only; the remaining accounts stay signed in and one of them becomes active.
Test hooks: [data-panel='user-menu'] · [data-section='accounts'|'organizations'|'language'|'actions'] · [data-account] · [data-organization] · [data-control='language-select'] · [data-action='add-account'].
