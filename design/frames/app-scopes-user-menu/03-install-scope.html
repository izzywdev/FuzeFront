Installing an app: where, and for whom

Every registered app declares a scope level — personal, organization, or both — and an organization install policy. Personal installs always remain personal. An app may require every organization install to be organization-wide; in that case the dialog states the fixed outcome instead of asking an invalid “me or everyone” question.

  • Installation is not the authorization boundary. visibility, org membership and Permit still gate what a user may see and do; scope decides only where an app lands.
  • Uninstall is a soft revoke, so an app can be uninstalled and reinstalled without colliding with the unique-per-target constraint.
