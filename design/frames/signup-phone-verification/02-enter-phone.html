Enter your phone number

PhoneNumberField = country calling-code select + national number, normalised client-side to E.164 (^\+[1-9]\d{7,14}$ plus per-country length rules via libphonenumber-js). The UI always shows the exact E.164 string it will send. Send code stays disabled until the number is valid. The server re-validates (Δ PHONE_INVALID). The country defaults to the browser locale.
