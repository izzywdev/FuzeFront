# Published benchmark results

Each file here is one run of [`../app-onboarding-benchmark.md`](../app-onboarding-benchmark.md),
copied from [`../results-template.md`](../results-template.md) and filled in
with numbers actually observed while running the procedure.

## Naming

`<YYYY-MM-DD>-<runner-handle>.md`, e.g. `2026-10-05-izzywdev.md`. If the same
runner publishes more than one run on the same day (e.g. cold vs. warm),
append `-cold` / `-warm`.

## Adding a result

1. Run the procedure in `../app-onboarding-benchmark.md`.
2. Copy `../results-template.md` to a new file here, named per the convention
   above.
3. Fill in every field from what you actually observed. Do not estimate.
4. Open a PR adding just that file. No other file in this repository should
   need to change.

There are no published results yet. The first one establishes this
benchmark's actual baseline — see `docs/benchmarks/README.md` for why no
baseline is pre-filled here.
