# Connector batch 2 and AI platform additions

These definitions use the shared connector platform and FuzeKeys vault from batch 1. Apply its migration and deploy FuzeKeys before enabling any new grant. Register the callback URL shown by Helm for each OAuth provider and provision credentials in the backend secret. Missing credentials leave the provider unavailable.

| Provider | OAuth secret keys | Read actions |
| --- | --- | --- |
| Google Sheets | Shared `GOOGLE_CLIENT_ID`, `GOOGLE_CLIENT_SECRET` | `spreadsheet`, `values` |
| Google Docs | Same Google client | `document` |
| Google Slides | Same Google client | `presentations`, `presentation` |
| Google Tasks | Same Google client | `lists`, `tasks` |
| Microsoft SharePoint | Shared `MICROSOFT_OAUTH_CLIENT_ID`, `MICROSOFT_OAUTH_CLIENT_SECRET` | `sites`, `lists` |
| Microsoft To Do | Same Microsoft client | `lists`, `tasks` |
| Jira Cloud | `JIRA_CONNECTOR_CLIENT_ID`, `JIRA_CONNECTOR_CLIENT_SECRET` | `sites`, `issues` |
| Confluence Cloud | `CONFLUENCE_CONNECTOR_CLIENT_ID`, `CONFLUENCE_CONNECTOR_CLIENT_SECRET` | `sites`, `pages` |
| Linear | `LINEAR_CONNECTOR_CLIENT_ID`, `LINEAR_CONNECTOR_CLIENT_SECRET` | `issues`, `teams` |
| Trello | `TRELLO_CONNECTOR_CLIENT_ID`, `TRELLO_CONNECTOR_CLIENT_SECRET` | `boards`, `card` |

The callback environment variables are generated by `deploy/helm/fuzefront/templates/backend.yaml`. Atlassian OAuth cloud access must be limited to resources returned by the user's grant.

OpenAI, Anthropic, Gemini, Vercel and Lovable use user-supplied API keys or access tokens. The Connectors page posts them over the authenticated backend route `POST /api/v1/connectors/:provider/credential`; the backend validates the key where supported and writes it to FuzeKeys under the delegated user identity. No key is returned to the browser after submission. Lovable API access requires a qualifying paid workspace. Vercel project access uses a user-generated token until its OAuth permission surface is generally available.

Base44's workspace-key descriptor is pending a verified read transport. Replit has a remote MCP capability manifest but awaits OAuth discovery and Streamable HTTP transport. Neither appears in the connectable catalog. Marketplace publisher agents prepare submission evidence and do not claim store publication.
