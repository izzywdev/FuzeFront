`HeroBand` — a FuzeFront design-system `layout` primitive, styled entirely with tokens.

**Props**

- `as?` — Element/component to render as. Default "section".
- `padding?` — Vertical padding, from the DS --space-* scale. Default "lg" (--space-24).
- `from?` — Gradient start color (CSS color value). Overrides --hero-band-from.
- `to?` — Gradient end color (CSS color value). Overrides --hero-band-to.
- `angle?` — Gradient direction (CSS `linear-gradient` direction/angle). Overrides --hero-band-angle.

See `components/index.d.ts` for the full prop contract.
