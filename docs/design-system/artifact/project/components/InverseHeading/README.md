`InverseHeading` — a FuzeFront design-system `layout` primitive, styled entirely with tokens.

**Props**

- `as?` — Element to render as (h1/h2/h3 — pick the right heading level). Default "h2".
- `size?` — Step of the DS type scale for the mobile -> sm(640px) responsive jump. Default "lg".
- `spacing?` — Bottom margin, from the DS spacing scale (mb-4 equivalent). Default "md".

See `components/index.d.ts` for the full prop contract.
