`FieldStatus` — a FuzeFront design-system `forms` primitive, styled entirely with tokens.

**Props**

- `state?` — Which state to render. `idle` shows nothing (but reserves height).
- `message?` — Message shown next to the state icon/spinner.
- `action?` — Optional trailing node (e.g. a "sign in instead" link).

See `components/index.d.ts` for the full prop contract.
