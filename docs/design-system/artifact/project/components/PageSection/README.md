`PageSection` — a FuzeFront design-system `layout` primitive, styled entirely with tokens.

**Props**

- `as?` — Element/component to render as. Default "section".
- `spacing?` — Block (top+bottom) padding, from the DS --space-16/20/24 scale. Default "lg".
- `background?` — Background surface token. Default "white" (var(--paper)).

See `components/index.d.ts` for the full prop contract.
