`Container` — a FuzeFront design-system `layout` primitive, styled entirely with tokens.

**Props**

- `as?` — Element/component to render as. Default "div".
- `size?` — Max-width, from the DS --container-* scale. Default "7xl".
- `gutter?` — Apply the responsive horizontal gutter (px-4/6/8 equivalent). Default true.

See `components/index.d.ts` for the full prop contract.
