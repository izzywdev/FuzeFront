`SectionHead` — a FuzeFront design-system `layout` primitive, styled entirely with tokens.

**Props**

- `kicker?` — Eyebrow pill label above the heading.
- `title` — Section heading text.
- `description?` — Optional descriptive paragraph below the heading.
- `viewAllLabel?` — Label for the "view all" link. If omitted, no link is rendered.
- `viewAllHref?` — URL for the "view all" link. Defaults to "#".
- `onViewAll?`

See `components/index.d.ts` for the full prop contract.
