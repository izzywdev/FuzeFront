`HeroSection` — a FuzeFront design-system `layout` primitive, styled entirely with tokens.

**Props**

- `as?` — Element/component to render as. Default "section".
- `containerSize?` — `Container` width for the hero content. Default "4xl".
- `align?` — Text alignment of the inner Container. Default "center".
- `decor?` — 0–2 blurred decorative blobs, pinned to a corner. Default none.
- `pattern?` — Render the dot-grid overlay. Default true.
- `gradient?` — Override the three diagonal gradient stops. Defaults to the brand slate→indigo hero gradient.
- `ref?`

See `components/index.d.ts` for the full prop contract.
