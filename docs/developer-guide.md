The previous contents of this file described an earlier iteration of the platform (a standalone
SDK package, Netlify/Vercel deploys, JWT-only auth) that no longer reflects FuzeFront. The current,
verified guidance — Module Federation shared-singleton contract, the `@fuzefront/*` packages,
Authentik SSO + Permit authorization, and GitOps deployment via Helm/Argo — lives in the Help
Center Developer Guide linked above.
